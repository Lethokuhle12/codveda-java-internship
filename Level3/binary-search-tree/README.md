# Binary Search Tree (Maven)

Simple BST in Java with insert, delete, search, and in-order / pre-order / post-order traversals.

## Requirements
- JDK 17+
- Maven 3.6+

## Commands
```
mvn test                         # run unit tests
mvn package                      # build target/bst-1.0.0.jar
java -jar target/bst-1.0.0.jar   # run the demo
```

## Structure
```
bst-maven/
├── pom.xml
└── src
    ├── main/java/com/example/bst/
    │   ├── TreeNode.java
    │   ├── BinarySearchTree.java
    │   └── Main.java
    └── test/java/com/example/bst/
        └── BinarySearchTreeTest.java
```
